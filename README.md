## Steam Enhanced

**The Steam you always wanted.**

A complete redesign of the Steam desktop client, its in-game overlay, and Steam's web pages, built for [Millennium](https://github.com/SteamClientHomebrew/Millennium). One coherent visual system, from the library to the smallest dialog.

  <tr>
    <td width="33%" valign="top">

    <td width="33%" valign="top">
      <b>Built around your games</b><br>
      <sub>Redesigned library, game pages, collections, and overlay.</sub>
    </td>
    <td width="33%" valign="top">
      <b>Made to feel native</b><br>
      <sub>A cohesive experience that works with the Steam client.</sub>
